# Second Screen PiP

Мод для BepInEx (R.E.P.O.): в окне хоста появляется окошко с экраном второй копии игры.
Ставится в ОБА окна (одна и та же DLL, ничего настраивать не нужно).

## Как собрать (один раз)
Ничего устанавливать не нужно - используется компилятор C#, который уже есть в Windows.
1. Распакуйте архив.
2. Папку игры `build.bat` находит сам через Steam (файл `find_game.ps1` должен лежать рядом).
   Если не нашёл - спросит путь, либо запустите `build.bat "E:\Games\REPO"` из cmd.
3. Дважды щёлкните `build.bat`. Он соберёт `out\SecondScreenPip.dll` и сам скопирует её в `BepInEx\plugins`.
4. Если сборка выдаст ошибку - пришлите её текст целиком.

## Как пользоваться
0. **F4** - переключиться на другое окно игры (работает в обоих окнах).
0. В окне хоста нажмите **F2** - запустится вторая копия REPO.exe (клавиша `LaunchKey`). Отдельный мод LocalMultiplayer больше не нужен - он встроен (`LocalMp.cs`, по мотивам Zehs/REPO-LocalMultiplayer, MIT).
   Во второй копии нажмите «Присоединиться» - она зайдёт в комнату хоста под другим Steam ID.
   Нужны свои Photon App ID (`AppIdRealtime`, `AppIdVoice`) в `BepInEx\config\local.secondscreenpip.cfg`;
   если у вас остался старый `global.cfg` от LocalMultiplayer, значения подхватятся из него сами.
   Старую `com.github.zehsteam.LocalMultiplayer.dll` из `plugins` удалите (`build.bat` делает это сам).
1. Запустите первое окно игры (хост) и создайте комнату.
2. Запустите второе окно. Не сворачивайте его (свёрнутое окно Unity не рисует кадры); можно держать
   его за первым или рядом.
3. В окне хоста появится окошко «Игрок 2». F8 - показать / скрыть. Окошко можно перетаскивать мышью
   (когда курсор свободен, например в меню).

Мод сам включает `Application.runInBackground`, чтобы неактивное окно не отваливалось от сервера.

## Настройки
Файл `BepInEx\config\local.secondscreenpip.cfg` (появляется после первого запуска):
- `Role` - Auto / Host / SecondWindow. Auto: первое окно - хост, остальные передают картинку.
- `ToggleKey`, `Width`, `X`, `Y`, `Title` - клавиша, размер, позиция и заголовок окошка.
- `Capture.Width`, `Fps`, `JpgQuality` - чёткость и частота кадров.
- `FlipVertical` - если картинка вверх ногами, переключите.

## Как это работает
Второе окно раз в долю секунды снимает свой экран (`ScreenCapture`), кодирует в JPEG и
кладёт в `%TEMP%\RepoSecondScreenPip\frame.jpg`. Хост читает файл и рисует его в IMGUI-окошке.
Сеть для этого не используется.

## Известные ограничения (не проверялось в игре)
- Код не компилировался и не запускался мной - возможны мелкие правки.
- Картинка может отличаться по цвету, если игра использует линейное пространство.
- Если второе окно свёрнуто, кадры не обновляются, и окошко покажет «Нет сигнала».
